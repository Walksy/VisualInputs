<h1>Visual Inputs</h1>

This mod shows which keys and buttons you pressed, and where in each game tick they were actually pressed.

---
### Features:

- Optional Flushed Inputs widget above the timeline which lists which inputs each tick actually handled in the order they were executed by the client
- Color code text depending on the input device
- Row count setting, plus optional release markers
- Move and resize both widgets
