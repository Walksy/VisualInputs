<h1>Visual Inputs</h1>

Shows which keys and buttons you pressed, and where in each game tick they were actually pressed.

This mod displays a widget that contains bars (which represent 0 to 50 ms, which is one whole tick), and every input is marked on it where the game received it.

---
### Features:

- Optional Flushed Inputs widget above the timeline which lists which inputs each tick actually handled in the order they were executed by the client
- Row count setting, plus optional release markers
- Move and resize both widgets
